# 🚀 Extension Chrome Job Journey - Guide d'Installation (30 secondes)

Cette extension officielle Job Journey vous permet d'importer n'importe quelle offre d'emploi en **1 seul clic**, sans aucun copier-coller ni manipulation technique.

Compatible avec :
- ✅ **Welcome to the Jungle** (Titre, Entreprise, Ville, Logo, Contrat CDI/CDD, Stack technique)
- ✅ **LinkedIn** (Titre, Entreprise, Lieu, Type de présence)
- ✅ **Indeed** (Titre, Entreprise, Salaire, Description complète, Contrat)
- ✅ **Apec** (Titre, Entreprise, Salaire 40k-50k, Contrat, Logo)
- ✅ **France Travail** (Titre, Numéro d'offre, Ville, Contrat)
- ✅ **N'importe quel autre site d'emploi** (extraction sémantique Schema.org / OpenGraph)

---

## 🛠️ Installation dans Google Chrome / Brave / Edge

1. Ouvrez Google Chrome et rendez-vous sur : `chrome://extensions/`
2. En haut à droite, **activez le bouton "Mode développeur"**.
3. En haut à gauche, cliquez sur le bouton **"Charger l'extension non empaquetée"**.
4. Sélectionnez le dossier :
   ```
   c:\Users\Maxence\Desktop\repositories\myjobboard\extension
   ```
5. Cliquez sur l'icône **Épingle (Pin)** dans la barre d'outils de Chrome pour garder l'icône Job Journey visible.

---

## 💡 Comment l'utiliser ?

1. Rendez-vous sur n'importe quelle offre d'emploi (sur Welcome to the Jungle, LinkedIn, Indeed, Apec, etc.).
2. Cliquez sur l'icône **Job Journey** dans votre barre d'outils Chrome.
3. Une jolie fenêtre s'ouvre et vous affiche immédiatement la prévisualisation des informations extraites.
4. Cliquez sur **« 🚀 Importer dans Job Journey »**.
5. C'est fait ! Votre offre est instantanément enregistrée dans votre tableau de bord Job Journey.
